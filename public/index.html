给展览馆投稿

选好学院，把作品拖进来，剩下的交给奶龙。

1

用 GitHub 登录

投稿会以 Pull Request 的形式提到主站仓库，作者是你自己的账号。 需要授权 public_repo 权限（GitHub 的粒度下限，用来创建仓库副本并提交）。

2

选择学院

3

添加作品

点这里选图片，或者把图片拖进来 支持多选 · 会自动转成 webp 并压缩 · 手机照片里的位置信息会被抹掉
    4

    提交

    提交后会创建 Pull Request。主站维护者合并后，作品会出现在 奶龙展览馆 对应学院的卡片里。
